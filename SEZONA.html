SEZONAТВОЯ ПРИРОДА

Версия 1.0 · Демоверсия

Сезонная атмосфера для рабочего стола. Веб-версия и основа приложения Windows.

Часть системных возможностей — живые обои поверх рабочего стола, курсоры Windows, автозапуск, эффекты поверх других окон и системный трей — требуют отдельной сборки Windows и не могут работать на статическом хостинге GitHub Pages.
